# 50th Wedding Anniversary — Telugu Golden Jubilee Digital Invitation
## స్వర్ణోత్సవ ఆహ్వాన పత్రిక

A divine, traditional, and mobile-first Telugu 50th Wedding Anniversary Digital Invitation website for **శ్రీమతి పుల్లగూర సుబ్బలక్షమ్మ** and **శ్రీ పుల్లగూర పెద్ద గోవిందస్వామి**, hosted with devotion by the Pullagura family.

---

### ✨ Features
- **Traditional Patrika Theme:** Sacred South Indian royal palette (warm ivory, kumkum maroon, antique temple gold, and champagne).
- **Opening Invitation Cover:** Interactive envelope opening ceremony with sacred slokams, auspicious 50 Years cartouche, and gold confetti.
- **Mobile-First Experience:** Optimized for smartphones with smooth horizontal navigation pills, touch-friendly buttons, and zero awkward whitespace gaps.
- **Comprehensive Event Schedule:** Live countdown timer to 30 October 2026, 4 ceremony timelines with clock badges, Google Calendar integration, and `.ICS` download.
- **Kalyana Mandapam & Directions:** Venue details for శ్రీ వాసవి కళ్యాణ మండపం (A/C), యర్రగుంట్ల with 1-tap Google Maps directions and address copy.
- **Family Cordial Invitation (మా కుటుంబం తరఫున ఆహ్వానం):** Three balanced groups:
  - కుమారులు (Sons)
  - కోడళ్ళు (Daughters-in-law)
  - మనుమలు & మనుమరాళ్ళు (Grandchildren)
- **Live Guestbook & Real-Time Blessings:** Powered by Firebase Firestore with real-time sync and moderation.
- **Admin Dashboard:** Passcode-protected (`1976` / `2026`) moderation panel with real-time synchronization, moderation controls, and CSV export.
- **Sacred Ambient Audio Player:** Floating traditional nadaswaram/shehnai devotional background music player.

### 🚀 Getting Started

#### Prerequisites
- Node.js (v18+)
- npm

#### Installation
```bash
# Clone the repository
git clone https://github.com/akshaykumarpullagura-2006/golden-jubliee-.git

# Navigate to project folder
cd golden-jubliee-

# Install dependencies
npm install

# Start local development server
npm run dev
```

#### Production Build
```bash
npm run build
npm run preview
```
